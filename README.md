# Web Scientific Calculator & 20x20 Spreadsheet (공학용 계산기 & 스프레드시트)

반응형 웹 기반 공학용 계산기(Casio fx 스타일)와 20×20 바둑판형 스프레드시트(Excel 호환 수식 및 실시간 합/평균/갯수 통계) 서비스입니다.

## ✨ 주요 기능
- **공학용 계산기**:
  - Casio fx 스타일 LCD 디스플레이 및 7행 키패드
  - 삼각함수, 역삼각함수, 쌍곡선함수, 순열(nPr), 조합(nCr), 팩토리얼(n!), 진법 변환(DEC/HEX/OCT/BIN), 메모리(M+/M-/MR/MS)
  - 마우스/터치 클릭 및 PC 키보드 수동 입력(숫자, 사칙연산, 엔터, 백스페이스, 단축키) 완벽 지원
- **20×20 스프레드시트**:
  - 20열 (A~T) × 20행 (1~20) 바둑판 그리드
  - `=SUM()`, `=AVERAGE()`, `=COUNT()`, `=MAX()`, `=MIN()`, 사칙연산 등 엑셀 호환 수식
  - 바둑판 하단에 입력된 모든 숫자의 **합계(SUM), 평균(AVG), 개수(COUNT)** 실시간 자동 집계
  - 계산기 결과 원클릭 입력, 예제 데이터 로드, CSV 내보내기
- **반응형 모바일 지원**:
  - 노트북/PC: 좌우 5:5 듀얼 패널 동시 노출
  - 스마트폰/모바일: 상단 2개 탭 및 슬라이딩 인디케이터 바, 좌우 스와이프 제스처 지원

## 🚀 로컬 실행
`index.html` 파일을 브라우저에서 열거나 정적 웹 서버로 실행합니다.
